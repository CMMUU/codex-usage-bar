# Codex Usage Bar v0.3.3

This maintenance release hardens Codex app-server compatibility across CLI,
proxy, protocol, and transient-network changes.

## Highlights

- Retries through the normal system route, a ChatGPT-scoped `NO_PROXY` route,
  and a final direct route when the local proxy is unavailable
- Supports both `codex app-server --stdio` and `--listen stdio://`
- Follows the initialized app-server handshake before requesting account data
- Accepts camelCase and snake_case payloads, minute/second window durations,
  numeric strings, and ISO-8601 reset timestamps
- Restores the last successful usage snapshot while a refresh is unavailable
- Discovers Codex from additional ChatGPT.app and user-local installation paths
- Adds deterministic compatibility coverage for the handshake and payload
  variants

## Installation

Use **Check for updates** in Codex Usage Bar v0.3.2, or download the latest DMG
from the latest release page:

https://github.com/CMMUU/codex-usage-bar/releases/latest

If macOS blocks the first launch, open **System Settings → Privacy & Security**
and choose **Open Anyway**.

## Verification

```bash
shasum -a 256 -c Codex-Usage-Bar-v0.3.3-universal.dmg.sha256
```
