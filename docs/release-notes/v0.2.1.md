# Codex Usage Bar v0.2.1

This maintenance release fixes widget updates for ad-hoc builds, introduces
a dedicated application icon, and adds a persistent Chinese/English interface
switch.

## Highlights

- Widget snapshots now fall back to a loopback-only Network.framework bridge
  when App Group access isn't authorized
- The widget caches the last successful snapshot inside its own sandbox
- No Codex credentials, tokens, or cookies are transferred through the bridge
- New cyan and violet macOS application icon
- Compact Simplified Chinese / English switch in the menu bar popover
- Widgets follow the language selected in the menu bar popover
- Localized labels, dates, empty states, accessibility text, and common errors
- Universal Apple Silicon and Intel DMG
- Ad-hoc signing for installation without an Apple Developer account

## Installation

1. Download `Codex-Usage-Bar-v0.2.1-universal.dmg`.
2. Quit the currently running Codex Usage Bar.
3. Replace the existing app in **Applications**.
4. Launch the app. If macOS blocks the first launch, open **System Settings →
   Privacy & Security** and choose **Open Anyway**.
5. Wait for the menu bar usage to refresh. The existing widget should update
   automatically; remove and add it again if macOS is still displaying a cached
   timeline from v0.2.0.

## Verification

```bash
shasum -a 256 -c Codex-Usage-Bar-v0.2.1-universal.dmg.sha256
```
