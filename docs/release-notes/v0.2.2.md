# Codex Usage Bar v0.2.2

This maintenance release makes the macOS widget and website widget previews
follow the language selected in Codex Usage Bar.

## Highlights

- The macOS widget now stores language independently from usage data
- Language changes reach the widget before the first successful usage refresh
- Ad-hoc builds retain language sync through the loopback-only bridge
- Cached widget timelines keep the most recently selected language
- The website widget previews now follow the global Chinese/English switch
- The redundant widget-only language switch has been removed

## Installation

Use **Check for updates** in Codex Usage Bar v0.2.1, or download the latest DMG
from the latest release page:

https://github.com/CMMUU/codex-usage-bar/releases/latest

If macOS blocks the first launch, open **System Settings → Privacy & Security**
and choose **Open Anyway**.

## Verification

```bash
shasum -a 256 -c Codex-Usage-Bar-v0.2.2-universal.dmg.sha256
```
