# Codex Usage Bar v0.4.1

Fixes Codex CLI discovery with the newer ChatGPT macOS app bundle, including
the installation layout observed after upgrading to macOS 27.

## Fixes

- Discovers the executable inside `codex-cli/CodexCLI.app` without requiring
  a terminal PATH or a manually configured `CODEX_BINARY_PATH`.
- Preserves explicit overrides, older ChatGPT bundle layouts, Homebrew,
  user-local installations, and PATH lookup.
- Skips directories and non-executable files when locating the CLI.
- Adds isolated discovery regression checks so a developer's installed CLI
  cannot hide a missing bundle-path fallback.

Validated with a live quota query on macOS 27.0.1 and Codex CLI 0.159.0 using
a minimal GUI-style PATH. The minimum supported macOS version remains 13.

## 中文说明

- 修复新版 ChatGPT 内置 CLI 路径变化导致的“未找到 Codex CLI”错误。
- 支持嵌套的 `CodexCLI.app`，无需手动配置环境变量或额外安装 CLI。
- 保留旧版路径与现有安装方式的兼容，跳过目录和不可执行文件。
- 已在 macOS 27.0.1、Codex CLI 0.159.0 下验证真实额度查询。

## Installation

Use **Check for updates** in the app, or download the universal DMG from this
release. The DMG supports Apple Silicon and Intel Macs and includes the WidgetKit
extension.

```bash
shasum -a 256 -c Codex-Usage-Bar-v0.4.1-universal.dmg.sha256
```
