# Codex Usage Bar v0.4.2

- Added the download center as the default installation and in-app update source.
- Future releases automatically sync to the center after SHA-256 and Sparkle signature verification.
- The website uses a permanent download link and retains an independent GitHub backup.
- Existing installations can upgrade through their original GitHub feed. macOS 27 CLI discovery and Kimi subscription quotas remain supported.

## 下载中心与自动更新

- 应用内“检查更新”改为从下载中心获取更新，继续验证 Sparkle EdDSA 签名。
- 后续发版自动同步并核验，下载中心的固定入口自动指向已验证的最新正式版。
- 官网默认使用下载中心，保留 GitHub 备用下载；旧版可通过原更新源升级。
- 保留 macOS 27 的 Codex CLI 路径兼容及 Kimi 订阅额度功能。
