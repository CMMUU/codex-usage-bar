# Codex Usage Bar v0.3.1

This release adds the 5-hour limit to the popover and the medium widget for
subscriptions that provide one, and fixes the medium widget layout so all
metrics stay inside the widget bounds.

## Highlights

- New compact 5-hour limit section in the popover: used percent, progress
  bar, remaining quota, and reset time
- Shown only when the subscription reports a 5-hour window — accounts without
  one keep the previous layout, and the row appears automatically if the
  limit is introduced later
- Works for both Codex (when the account includes a session window) and K3
  (from the Kimi usages limits array)
- The medium widget shows the 5-hour limit as a metric row and switches to
  single-line rows so all four metrics and the updated timestamp fit
- The K3 main window subtitle no longer assumes a window duration

## Installation

Use **Check for updates** in Codex Usage Bar v0.3.0, or download the latest
DMG from the latest release page:

https://github.com/CMMUU/codex-usage-bar/releases/latest

Updating the app also updates the bundled widget; remove and re-add the
widget from the gallery if macOS keeps showing an older layout.

## Verification

```bash
shasum -a 256 -c Codex-Usage-Bar-v0.3.1-universal.dmg.sha256
```
