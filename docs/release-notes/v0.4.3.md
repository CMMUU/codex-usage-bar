# Codex Usage Bar v0.4.3

- Fixed widgets showing an older quota while the menu bar app has already refreshed, including when an App Group file remains readable but cannot be updated.
- Publish quota, selected subscription, and language together. Switching Codex/Kimi clears the previous subscription's quota while the new one loads.
- Keep the latest complete cached state when the app is closed, preserving the actual quota refresh time.
- Handle fragmented local responses correctly and request widget refreshes on the same five-minute schedule as the app. WidgetKit controls the actual rendering time.
- Available through the download center and the app's update button.

## 小组件额度同步修复

- 小组件优先读取运行中主应用的最新状态，修复共享目录旧快照盖过新额度的问题。
- 额度、订阅选择及语言统一同步；切换 Codex/Kimi 时立即发布清空状态，避免显示上一订阅的额度。
- 应用关闭后使用最新完整缓存；切换语言不会把旧额度标记为刚刚刷新。
- 修复本机通信分段到达时读取不完整的问题；小组件与主应用均按五分钟周期请求更新，实际绘制时间由 macOS 调度。
- 可通过下载中心或应用内“检查更新”升级。
