# Codex Usage Bar v0.4.7

- Adds Claude Code, Google Antigravity, GitHub Copilot, GLM Coding Plan, MiniMax, Alibaba Model Studio, and Volcengine Ark alongside Codex and Kimi.
- The menu bar and widgets share the selected subscription, plan, used and remaining quota, and reset times. The small widget shows the primary quota and the medium widget shows up to three windows.
- Quota values keep the provider's units. Missing values display as unavailable, and older readings keep their original update time.

## Connect a subscription

- **Claude Code and Antigravity.** Select the subscription, open **Manage connection**, and copy the setup command into the official CLI status line. Open a CLI session that reports quota. [Claude Code setup](https://code.claude.com/docs/en/statusline) · [Antigravity setup](https://antigravity.google/docs/cli/statusline#configuration)
- **GitHub Copilot, Alibaba Model Studio, and Volcengine Ark.** Sign in to the official `copilot`, `bl`, or `arkcli` CLI, then refresh the selected subscription in the app. The Ark integration reads the personal Coding Plan.
- **GLM and MiniMax.** Enter the subscription API key under **Manage connection**. The app stores it in the Mac keychain.

### 接入方式

- **Claude Code 和 Antigravity** 在「管理连接」复制命令，加入官方 CLI 的状态行配置，等 CLI 会话提供额度。[Claude Code 配置](https://code.claude.com/docs/en/statusline) · [Antigravity 配置](https://antigravity.google/docs/cli/statusline#configuration)
- **GitHub Copilot、阿里云百炼和火山方舟** 登录官方 `copilot`、`bl` 或 `arkcli` 后，在应用里选择相应订阅并刷新。火山方舟接入个人 Coding Plan。
- **智谱 GLM 和 MiniMax** 在「管理连接」输入套餐 API 密钥。密钥保存于 macOS 钥匙串。
