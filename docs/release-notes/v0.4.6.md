# Codex Usage Bar v0.4.6

- Use a stable Developer ID signature and a matching Team ID-prefixed macOS App Group for the app and widget.
- Stop reading shared preferences during widget initialization and skip fallback storage when live usage is available.
- Keep the latest app state in a private cache, record sync failures, and show the real update time in both widget sizes.
- Schedule an explicit stale display so a delayed timeline cannot keep old usage looking current.
- Require Developer ID signing, notarization, and matching app/widget capabilities before publishing official updates.

## 中文

- 应用与小组件使用稳定的 Developer ID 正式签名及同团队 App Group，修复共享目录访问被拒绝的问题。
- 小组件初始化不再读取共享偏好；读取到实时额度后立即使用，避免额外访问旧数据路径。
- 主应用保存私有恢复缓存，同步失败写入诊断日志；两种尺寸的小组件均显示真实更新时间。
- 预先安排额度过期提示，系统延迟刷新时不会长期将旧额度显示为最新状态。
- 正式更新必须通过签名、公证和应用/小组件共享能力核验。
