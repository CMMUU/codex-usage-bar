# Codex Usage Bar v0.3.4

This maintenance release restores K3 usage parsing for the current Kimi for
Coding response format.

## Highlights

- Supports Kimi usage responses that provide `remaining` instead of `used`
- Derives used percentage from `limit - remaining` for the main and 5-hour
  windows
- Accepts camelCase and snake_case fields, numeric values, and numeric strings
- Keeps compatibility with the previous `used` response format
- Adds deterministic coverage for the current remaining-only response shape

## Installation

Use **Check for updates** in Codex Usage Bar v0.3.3, or download the latest DMG
from the latest release page:

https://github.com/CMMUU/codex-usage-bar/releases/latest

If macOS blocks the first launch, open **System Settings → Privacy & Security**
and choose **Open Anyway**.

## Verification

```bash
shasum -a 256 -c Codex-Usage-Bar-v0.3.4-universal.dmg.sha256
```
