# Codex Usage Bar v0.3.2

This maintenance release makes the Chinese/English switch reliable during
usage refreshes and keeps the menu bar app and macOS widget on the same
language state.

## Highlights

- The requested language button shows an inline loading spinner while the
  refresh transaction is in progress
- Language buttons are temporarily locked so rapid clicks cannot cancel or
  lose a pending switch
- The selected language is applied only after the refresh completes, including
  the refresh-error path
- Widget preferences, shared snapshots, and the local widget bridge are
  updated together after the language switch is committed
- Added deterministic verifier coverage for rapid repeated clicks and the
  final Widget language state

## Installation

Use **Check for updates** in Codex Usage Bar v0.3.1, or download the latest DMG
from the latest release page:

https://github.com/CMMUU/codex-usage-bar/releases/latest

If macOS blocks the first launch, open **System Settings → Privacy & Security**
and choose **Open Anyway**.

## Verification

```bash
shasum -a 256 -c Codex-Usage-Bar-v0.3.2-universal.dmg.sha256
```
