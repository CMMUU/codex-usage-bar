# Codex Usage Bar v0.1.0

Initial open-source release.

## Highlights

- Native macOS menu bar interface
- Weekly Codex usage and remaining capacity
- Reset time, plan, and limit-name display
- Five-minute automatic refresh
- Manual refresh and launch-at-login support
- Local Codex app-server integration
- No direct authentication-file or browser-cookie access
- Deterministic verifier and macOS CI

## Installation

This is a source-first release:

```bash
git clone https://github.com/CMMUU/codex-usage-bar.git
cd codex-usage-bar
make package
open "dist/Codex Usage Bar.app"
```

The generated app uses an ad-hoc signature. Developer ID-signed and notarized
downloads are planned for a future release.
