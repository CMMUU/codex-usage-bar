# Codex Usage Bar v0.3.0

This release adds K3 (Kimi for Coding) quota support alongside Codex, with a
subscription switcher shared by the popover, the menu bar label, and the
widgets.

## Highlights

- New K3 (Kimi for Coding) 5-hour window usage, remaining quota, reset time,
  and membership level
- Subscription dropdown in the popover switches between Codex and K3
- The menu bar label and the widgets follow the selected subscription
- K3 credentials are read from the local kimi-code credentials file, refreshed
  in place with atomic writes, and never leave your Mac
- Window-aware wording: weekly limit for Codex, 5-hour window for K3, in both
  Simplified Chinese and English
- Widget snapshot and preferences stay backward compatible with older app and
  widget builds

## Installation

Use **Check for updates** in Codex Usage Bar v0.2.2, or download the latest DMG
from the latest release page:

https://github.com/CMMUU/codex-usage-bar/releases/latest

If macOS blocks the first launch, open **System Settings → Privacy & Security**
and choose **Open Anyway**.

To show K3 usage, sign in once with the kimi CLI (`kimi login`). The app
refreshes the short-lived OAuth token automatically.
