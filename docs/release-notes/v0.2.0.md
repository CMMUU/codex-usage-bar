# Codex Usage Bar v0.2.0

This release adds native macOS widgets and a complete universal-DMG
distribution pipeline.

## Highlights

- Native WidgetKit extension for the macOS desktop and Notification Center
- Small and medium widget layouts
- Weekly usage, remaining capacity, reset time, and stale-data indication
- Private App Group snapshot shared between the menu bar app and widget
- Universal Apple Silicon and Intel application bundle
- Ad-hoc signing so GitHub Releases can be published without an Apple Developer
  account
- Automatic Developer ID signing, Apple notarization, and stapling when release
  credentials are configured
- DMG and SHA-256 checksum assets attached directly to the GitHub Release
- GitHub artifact attestation for release provenance

## Installation

1. Download `Codex-Usage-Bar-v0.2.0-universal.dmg`.
2. Open the DMG and drag **Codex Usage Bar** to **Applications**.
3. Launch the app. If macOS blocks the first launch, open **System Settings →
   Privacy & Security** and choose **Open Anyway**.
4. Wait for the first successful refresh.
5. Add **Codex 周限额** from the macOS widget gallery.

This release is ad-hoc signed and isn't notarized by Apple. The menu bar app is
fully usable after the one-time Gatekeeper confirmation. The embedded widget is
included, but App Group data sharing can require additional authorization on
macOS 15 and later.
