# Codex Usage Bar v0.4.0

Kimi quota tracking now follows the subscription instead of a model name.

## Highlights

- Replaces K3 with Kimi in the menu bar, subscription picker, widgets, and errors.
- Reads current Kimi usage responses and retains support for the previous format.
- Shows the monthly membership quota when provided, with separate weekly and
  5-hour Code limits and their own reset times. When monthly data is unavailable,
  the displayed percentage explicitly identifies the available window.
- Preserves saved K3 selections and cached usage during the upgrade.
- Keeps Code's monthly contribution from being counted twice and hides quota
  windows that the account does not provide.
- Keeps Codex quota tracking and the existing update mechanism.

## 中文说明

- 将 K3 统一调整为 Kimi，额度展示不再绑定单个模型。
- 兼容新旧接口；优先显示实际返回的会员月额度，分别显示周限额和 5 小时限额。
- 没有月额度时明确标识当前窗口；旧订阅选择和缓存可自动兼容。
- 月额度中的 Code 用量不重复累加，未返回的窗口不虚构为 0%。

## Installation

Use **Check for updates** in the app, or download the universal DMG from this
release. The DMG supports Apple Silicon and Intel Macs and includes the WidgetKit
extension.

```bash
shasum -a 256 -c Codex-Usage-Bar-v0.4.0-universal.dmg.sha256
```
