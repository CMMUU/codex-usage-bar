## 中文

- 修复 macOS 升级应用后，桌面小组件可能继续显示旧额度的问题。
- 新版首次启动时核验并退出仍在运行的旧版小组件扩展，随后请求 macOS 加载与菜单栏共用的最新额度。

## English

- Fixed desktop widgets showing outdated quota after an app update on macOS.
- On the first launch of a new build, the app exits verified older widget extensions and asks macOS to reload the latest quota shared with the menu bar.
